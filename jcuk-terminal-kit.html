CHNT JCUK-2.5N DIN Rail Terminal Block Kit

Brand new CHNT JCUK-2.5N screw-clamp terminal blocks supplied as a ready-to-install kit: 50 pieces, 1 meter TH35-7.5 galvanized steel DIN rail, and 2 matching end covers. Built for control panel wiring, motor starters, relay distribution and PLC I/O blocks.

This kit uses the standard 35mm top-hat DIN rail footprint and the same mounting dimensions as Phoenix UK2.5B and Weidmüller SAK2.5 style terminals — direct drop-in fit for panels already designed around those series.

Direct replacement / equivalent for: Phoenix Contact UK2.5B / UK3N, Weidmüller SAK 2.5 / SAK 4, Delixi UK-2.5N and other IEC 60947-7-1 screw-type DIN rail terminals.

  • Model CHNT JCUK-2.5N (also written UK-2.5N)
  • Type Feed-through screw clamp terminal block
  • Wire size 0.2mm² – 2.5mm² (solid / stranded with ferrule)
  • Rated current 32A
  • Rated voltage 800V
  • Mounting 35mm DIN rail TH35-7.5 (top hat)
  • Material PA66 flame-retardant housing, nickel-plated brass conductor
  • Kit contents 50× JCUK-2.5N terminals + 1m TH35-7.5 rail + 2× end covers
